05

À faire / À éviter

✓ À faire
Utiliser l'orange pour UNE action principale par écran. Utiliser le vert pour rassurer (profil vérifié, trajet organisé). Garder les écrans aérés, fond clair crème/blanc. Le noir #1D1D1B pour le texte principal.
✗ À éviter
Mélanger orange et vert sur le même bouton. Utiliser plus de 2 couleurs par écran. L'orange en très grande surface (fatigant). Modifier les couleurs du logo. Utiliser du texte coloré sur fond orange.
