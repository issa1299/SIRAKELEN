Phase 2 — UX · Back-office Admin

SIRA KELEN — Dashboard administrateur

Version web (navigateur), réservée à l'équipe. Vue d'ensemble du système, gestion des utilisateurs, des AD et des signalements. Première version volontairement simple, alignée sur le MVP : les statistiques détaillées arrivent en v2.

Portée de cette première version
  • 4 onglets seulement : Aperçu (stats), Utilisateurs, Avis de Déplacement, Signalements.
  • Chaque écran = un tableau simple + actions directes (bloquer, supprimer, marquer traité).
  • Le badge rouge sur « Signalements » montre les dossiers en attente.
  • Accessible uniquement avec un compte administrateur — pas de création de compte libre.
